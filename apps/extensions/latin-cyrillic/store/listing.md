# Store listing — detailed description

The NAME and the SHORT description come from `public/_locales/*/messages.json`
(`extName`, `extDescription`) and ship inside the zip. The DETAILED description
does not: the Chrome Web Store, Edge Add-ons and addons.mozilla.org each keep
it in their own dashboard, per language. This file is its source — paste each
block into that language's field when uploading a version that changes it.

Plain text only (the stores strip Markdown). Version: 1.1.0.

The new letters below are the code points Law OʻRQ-1184 publishes (Ş U+015E,
Ç U+00C7, Ğ U+011E, Ö U+00D6) — not the look-alikes. Check before pasting.

## uz

O'zbek matnini lotin, kirill va yangi alifbo (2027) o'rtasida o'giring — istalgan saytda, sahifadan chiqmasdan.

YANGI: 2027-yilgi yangi lotin alifbosi
22-apreldan kuchga kiradigan yangi alifboga bir bosishda o'giring: sh → ş, ch → ç, g' → ğ, o' → ö. Lotin yoki kirill yozuvidagi matn ham, yarim o'girilgan hujjat ham to'g'ri chiqadi. Popup'da «Yangi lotin»ni tanlasangiz, sahifadagi panel va Ctrl+Shift+L ham shu alifboda ishlaydi.

Qanday ishlaydi
• Matnni belgilang — yonida tugma chiqadi. Bossangiz, natija o'sha yerning o'zida ochiladi.
• O'ng tugma menyusida ham bor.
• Ctrl+Shift+L (macOS'da ⌘+Shift+L) — belgilangan matnni o'girib, darhol nusxalaydi.
• Tahrirlanadigan maydonda «Almashtirish» tugmasi matnni joyida almashtiradi.
• Yo'nalish avtomatik aniqlanadi: kirillcha matn lotinga, lotincha kirillga.

Aniq o'giradi
O'zbek imlosining murakkab joylari hisobga olingan: sh va ch chegarasi (ishchi → ишчи), tutuq belgisi (san'at → санъат), -tsiya qo'shimchasi. Havolalar, e-pochta manzillari va kod o'zgarishsiz qoladi.

Maxfiylik
Matn brauzeringizdan chiqmaydi. O'girish qurilmangizning o'zida bajariladi, kengaytma hech qanday serverga so'rov yubormaydi va internetsiz ham ishlaydi.

Word yoki PDF faylni o'girish kerakmi? webiston.uz/tools/latin-cyrillic — fayllarni ham o'giradi.

## en

Convert Uzbek text between Latin, Cyrillic and the new 2027 alphabet — on any website, without leaving the page.

NEW: the 2027 Uzbek Latin alphabet
Convert into the alphabet that takes effect on 22 April 2027 in one click: sh → ş, ch → ç, g' → ğ, o' → ö. Text in Latin or Cyrillic, or a half-converted document, comes out right. Pick “New Latin” in the popup and the in-page panel and Ctrl+Shift+L use it too.

How it works
• Select text — a button appears next to it. Click it and the result opens right there.
• It is in the right-click menu as well.
• Ctrl+Shift+L (⌘+Shift+L on macOS) converts the selection and copies it.
• In an editable field, “Replace” swaps the text in place.
• The direction is detected for you: Cyrillic goes to Latin, Latin to Cyrillic.

Accurate
Handles the hard parts of Uzbek spelling: the sh/ch boundary (ishchi → ишчи), the tutuq mark (san'at → санъат), the -tsiya suffix. Links, e-mail addresses and code are left untouched.

Private
Your text never leaves the browser. Conversion runs on your device, the extension makes no network requests and works offline.

Need to convert a Word or PDF file? webiston.uz/en/tools/latin-cyrillic handles files.

## ru

Переводите узбекский текст между латиницей, кириллицей и новым алфавитом 2027 года — на любом сайте, не покидая страницу.

НОВОЕ: новый узбекский латинский алфавит 2027 года
Перевод в алфавит, который вступает в силу 22 апреля 2027 года, в один клик: sh → ş, ch → ç, g' → ğ, o' → ö. Текст на латинице или кириллице и даже наполовину переведённый документ получаются правильно. Выберите «Latin 2027» во всплывающем окне — панель на странице и Ctrl+Shift+L тоже будут работать с ним.

Как это работает
• Выделите текст — рядом появится кнопка. Нажмите, и результат откроется прямо там.
• Есть и в контекстном меню.
• Ctrl+Shift+L (⌘+Shift+L на macOS) переводит выделение и сразу копирует.
• В редактируемом поле кнопка «Заменить» меняет текст на месте.
• Направление определяется автоматически: кириллица — в латиницу, латиница — в кириллицу.

Точно
Учитывает сложные места узбекской орфографии: границу sh/ch (ishchi → ишчи), знак тутук (san'at → санъат), суффикс -tsiya. Ссылки, адреса почты и код остаются без изменений.

Приватно
Текст не покидает браузер. Перевод выполняется на вашем устройстве, расширение не обращается к сети и работает без интернета.

Нужно перевести файл Word или PDF? webiston.uz/ru/tools/latin-cyrillic умеет и это.
