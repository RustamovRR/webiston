# Store listing — detailed description

The NAME and the SHORT description come from `public/_locales/*/messages.json`
(`extName`, `extDescription`) and ship inside the zip — the dashboard shows
them as "Title from package" / "Summary from package" and cannot edit them.
The DETAILED description does not ship: the Chrome Web Store, Edge Add-ons
and addons.mozilla.org each keep it in their own dashboard, per language.
This file is its source — paste each block into that language's field.

Plain text only (the stores strip Markdown). Version: 1.1.0. Merged with the
1.0.x Chrome text (panel dragging, light/dark, the site link) on 2026-10-26.

The new letters below are the code points Law OʻRQ-1184 publishes (Ş U+015E,
Ç U+00C7, Ğ U+011E, Ö U+00D6) — not the look-alikes. Every example is the
engine's real output.

## uz

O'zbek matnini lotin, kirill va yangi alifbo (2027) o'rtasida o'giradi — istalgan saytda, sahifadan chiqmasdan.

YANGI: 2027-YILGI YANGI LOTIN ALIFBOSI
• 2027-yil 22-apreldan kuchga kiradigan alifboga bir bosishda o'giring: sh → ş, ch → ç, g' → ğ, o' → ö
• Lotin yoki kirill yozuvidagi matn ham, yarim o'girilgan hujjat ham to'g'ri chiqadi
• Popup'da «Yangi lotin»ni tanlang — sahifadagi panel va Ctrl+Shift+L ham shu alifboda ishlaydi

IMKONIYATLAR
• Istalgan veb-sahifada matnni tanlang — yonida kichik tugma chiqadi
• O'ng tugma menyusidan ham ishlaydi
• Ctrl+Shift+L (Mac: ⌘+Shift+L) — tanlangan matnni o'girib, darhol nusxalaydi
• Tahrirlanadigan maydonda «Almashtirish» tugmasi matnni joyida almashtiradi
• Yo'nalish avtomatik aniqlanadi: kirillcha matn lotinga, lotincha kirillga
• Panelni istagan joyingizga surib qo'yishingiz mumkin
• Yorug' va qorong'i rejim

ANIQ O'GIRADI
O'zbek imlosining murakkab joylari hisobga olingan: sh va ch chegarasi (ishchi → ишчи), tutuq belgisi (san'at → санъат), -tsiya qo'shimchasi (informatsiya → информация). Havolalar, e-pochta manzillari va kod o'zgarishsiz qoladi.

MAXFIYLIK: matningiz brauzeringizdan chiqmaydi. O'girish butunlay qurilmangizda bajariladi, hech qanday serverga yuborilmaydi. Internetsiz ham ishlaydi.

Word yoki PDF faylni o'girish (to'liq versiya): https://webiston.uz/tools/latin-cyrillic
Yangi alifbo haqida batafsil: https://webiston.uz/tools/yangi-alifbo

## en

Convert Uzbek text between Latin, Cyrillic and the new 2027 alphabet — on any website, without leaving the page.

NEW: THE 2027 UZBEK LATIN ALPHABET
• Convert into the alphabet that takes effect on 22 April 2027 in one click: sh → ş, ch → ç, g' → ğ, o' → ö
• Text in Latin or Cyrillic, or a half-converted document, comes out right
• Pick “New Latin” in the popup — the in-page panel and Ctrl+Shift+L use it too

FEATURES
• Select text on any web page — a small button appears beside it
• Works from the right-click menu too
• Ctrl+Shift+L (Mac: ⌘+Shift+L) converts the selection and copies it instantly
• In an editable field, “Replace” swaps the text in place
• The direction is detected for you: Cyrillic goes to Latin, Latin to Cyrillic
• Drag the panel anywhere you like
• Light and dark mode

ACCURATE
Handles the hard parts of Uzbek spelling: the sh/ch boundary (ishchi → ишчи), the tutuq mark (san'at → санъат), the -tsiya suffix (informatsiya → информация). Links, e-mail addresses and code are left untouched.

PRIVACY: your text never leaves the browser. Conversion runs entirely on your device and nothing is sent to any server. Works offline.

Convert a Word or PDF file (full version): https://webiston.uz/en/tools/latin-cyrillic
More about the new alphabet: https://webiston.uz/en/tools/yangi-alifbo
